## Story

Most résumés are a Word document someone is quietly ashamed of. Mine is a typesetting
project. It builds to four PDFs — a one-page **résumé** and a longer **CV**, each in a
**light** and a **dark** variant — all set in LaTeX so the typography is deliberate and
the output is identical every time.

The public repository here is the content. The build is done by a private engine I call
`radix`, which holds this repo as a submodule and drives the LaTeX toolchain — the same
separation-of-concerns idea as everything else I build: the words are open, the machinery
that presses them is its own thing. Read the rendered site at
[resume.starikov.io](https://resume.starikov.io), or take the PDFs directly:

- [Résumé — light](https://resume.starikov.io/illya-starikov-resume.pdf)
- [Résumé — dark](https://resume.starikov.io/illya-starikov-resume-dark.pdf)
- [CV — light](https://resume.starikov.io/illya-starikov-cv.pdf)
- [CV — dark](https://resume.starikov.io/illya-starikov-cv-dark.pdf)

The résumé is for the recruiter with thirty seconds; the CV is for anyone who wants the
whole story. Dark variants exist because I read everything in dark mode and assume you might
too.
